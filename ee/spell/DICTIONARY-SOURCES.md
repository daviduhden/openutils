# en_US dictionary: sources and provenance

The files `en_US.aff` and `en_US.dic` in this directory are dedicated to the
public domain under CC0-1.0; see [`LICENSES/CC0-1.0`](../../LICENSES/CC0-1.0).
`en_US.aff` was written from scratch for ee. `en_US.dic` is compiled
exclusively from word lists that their authors explicitly placed in the
public domain. No part of it comes from SCOWL, Hunspell, LibreOffice,
Mozilla, OpenOffice, Ispell, Aspell or any other dictionary project.

## What was extracted and filtered

- Only lowercase words matching `^[a-z]+$`, plus common contractions and
  possessives matching
  `^[a-z]+'(s|t|d|ll|re|ve|m|clock)$`.
- **Excluded:** proper names and initialisms (their original entries are
  capitalised, so they do not match the filter), abbreviations with a
  trailing dot, multi-word phrases, and hyphenated compounds (ee treats the
  hyphen as a word separator, so such entries would be unreachable).
- 12dicts `2of12` already excludes multi-word phrases and proper names by
  design; this was confirmed against its ReadMe.

## Normalisations

- CRLF line endings were stripped.
- Entries were not case-folded (the sources are already lowercase).
- Duplicates between `2of12` and `3esl` were removed by set union.
- The final list is sorted bytewise and carries no duplicate words.

## Combining the sources and British variants

- `2of12` and `3esl` are American-English lists; the union is the base
  vocabulary. No British-only list is used. When a British spelling appears
  in a source but an American form is preferred, only the American form is
  kept; the British form is simply not added.
- ENABLE2K contributes no base words; it is consulted only to confirm that a
  generated inflection is a real word. This keeps word-game and dialect
  vocabulary out of the dictionary.

## Affix flags and explicit forms

- `en_US.aff` defines six suffix flags and three prefix flags (see the file
  itself and [`README.md`](README.md)).
- A flag is added to a base word only when the single form its rule would
  produce is present in ENABLE2K. Because each flag's rules have disjoint
  conditions, every flagged word yields exactly one form per flag, so the
  rules cannot invent words.
- Regular inflections are therefore generated by the rules; they are not
  repeated in the dictionary.
- Irregular or double-consonant forms that the rules cannot express
  (`stopped`, `planned`, `bigger`, `potatoes`, `dying`, `fully`, ...) are
  listed explicitly in `en_US.dic`, and are added only when they are present
  in ENABLE2K.
- A word that would need two affixes at once (for example an irregular
  plural of an `un-` word) is listed explicitly instead, because ee's
  checker applies at most one prefix or one suffix.

## Reproducing en_US.dic

`gen-dictionary.pl` is a developer tool (core Perl); it is not part of the
build and performs no network access. Download the three sources above,
then run:

```sh
perl gen-dictionary.pl 2of12.txt 3esl.txt enable2k.txt en_US.dic
```

The output is deterministic: the entry list is sorted, duplicates are
removed by construction, and flags are emitted in a fixed order. The
generator writes the current `en_US.dic` byte for byte; it is committed to
the repository and is not regenerated during the build.
